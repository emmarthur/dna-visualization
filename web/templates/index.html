About this app


        


          A simple animation of a DNA double helix built from text characters.

          Each row shows base pairs (A–T and C–G) between ladder rungs, scrolling

          upward in a continuous stream.

        


        
How to use it


        
    

          
  • Run starts the animation (about {{ pause_seconds }} seconds between rows).
    • 

          
  • Pause stops new rows from appearing.
    • 

          
  • Clear empties the display; run again to restart.
    • 

          
  • The view keeps the most recent lines and scrolls automatically.
